# v204 — হোম "বিভাগসমূহ": বিশ্ব মানচিত্র কার্ড ঠিক করা

❌ **সমস্যা (UX / polish):** "ইবাদত ও টুলস"-এর ৭ম কার্ড (বিশ্ব মানচিত্র) ডেস্কটপে পুরো সারি জুড়ে লম্বা হয়ে যাচ্ছিল, অন্য কার্ডের সাথে মিলছিল না।

✓ **কারণ:** "শেষ কার্ড বেজোড় হলে পুরো সারি নেবে" নিয়মটি ২-কলামের ফোনের জন্য বানানো ছিল, কিন্তু ডেস্কটপেও (৪ কলাম) চলছিল।

✓ **ফিক্স:** নিয়মটি এখন শুধু ফোনে (≤৭৬৭px) প্রযোজ্য। ডেস্কটপ/ট্যাবলেটে (৪ কলাম) বিশ্ব মানচিত্র বাকি কার্ডের মতোই সাধারণ আকারের কার্ড। ফোনে আগের মতোই (৭টি কার্ড, শেষটি পুরো প্রস্থে)।
