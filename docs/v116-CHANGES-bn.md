# v116 — স্প্ল্যাশ: Allah SVG দুইবার ডাউনলোড হওয়া বন্ধ

**দৃশ্যমান কোনো বদল নেই।** লেখা, লেআউট, অ্যানিমেশন, ফন্ট সব v115-এর মতোই।

## কী বদলেছে
- **`index.html`** — `<link rel="preload" as="image" href="assets/images/splash-allah.svg">`-এ শুধু `crossorigin` অ্যাট্রিবিউট যোগ। CSS `mask: url(splash-allah.svg)` ফাইলটি CORS মোডে আনে; preload-এ অ্যাট্রিবিউট না থাকায় ব্রাউজার preload-করা কপি ব্যবহার করত না (Chrome warning দিত) এবং ~৯KB ফাইল দুইবার নামত।
- **`sw.js`** — CACHE v116 (index.html বদলেছে, তাই ইনস্টল করা PWA রিফ্রেশ হবে)।

## যাচাই
`node --check` (sw.js + সব JS) · স্মোক-টেস্ট · হেডলেস Chromium-এ `splash-allah.svg` রিকোয়েস্ট ২ → ১, preload warning নেই, স্প্ল্যাশ ঠিকমতো দেখায় ও নামে।

## যা ইচ্ছা করে বদলানো হয়নি
পোর্ট্রেট ফোনে ছোট ফন্ট: অডিটে প্রথমে মনে হয়েছিল শুভেচ্ছা লাইন ১০–১১px। পরে যাচাইয়ে দেখা গেছে `.k`/`.p` লাইন সব পোর্ট্রেট মাপে (৩২০–৪১২px) ১২px সর্বনিম্ন সীমায় আছে; শুধু ৩২০px-এ বিসমিল্লাহ ১১.৮px। তাই কোনো ফন্ট বদল করা হয়নি।
