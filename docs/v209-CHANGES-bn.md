# v209 — আজকের হাদিস/আয়াত/কুইজ: দিন-সংখ্যা DST ফিক্স

বেসলাইন: v208 · CACHE `ahlbayt-v209`

## সমস্যা
আটটি জায়গায় একই সূত্র ছিল: `Math.floor((now - new Date(বছর, 0, 0)) / 86400000)`। ১ জানুয়ারির আগের মধ্যরাত থেকে "এখন" পর্যন্ত মিলিসেকেন্ড ভাগ করা হতো। DST চালু থাকা অঞ্চলে (গ্রীষ্মকালীন সময়) এই ব্যবধান ১ ঘণ্টা কম, তাই মধ্যরাতের পর প্রথম ঘণ্টায় দিন-সংখ্যা ১ কম আসত — আজকের আয়াত/হাদিস/কুইজ আগের দিনেরটা দেখাত।

## ফিক্স
`script-1-core.js`-এ নতুন `dayOfYearLocal(now)` (স্থানীয় তারিখের বছর-মাস-দিন নিয়ে UTC-তে গণনা) এবং আটটি জায়গায় পুরনো সূত্রের বদলে এই কল:
- `script-1-core.js`: আজকের আয়াত, আজকের হাদিস, দৈনিক কুইজের seed, হোম কুইজ index (৪টি)
- `script-2-ui.js`: ayahNext / ayahPrev / hadithNext / hadithPrev (৪টি)
কোনো ফাংশনের নাম বা সিগনেচার বদলায়নি। যেখানে DST নেই (বাংলাদেশ) ফলাফল হুবহু আগের মতো।
