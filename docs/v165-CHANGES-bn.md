# v165 — হিজরি লিপ-ইয়ার তালিকা এক করা

**সমস্যা:** `approxHijriNow()`-এর ভেতরের `_hmd()`-এ লিপ-ইয়ার তালিকায় ১৫ ছিল, আর `getHijriMonthDays()`-এ (Bug #29 ফিক্সের পর) ১৬। তাই "আজকের হিজরি তারিখ" আর ক্যালেন্ডারের মাসের দৈর্ঘ্য কিছু বছরে (বছর % ৩০ = ১৫ বা ১৬) ভিন্ন হতো।

**বদল:** `script-1-core.js`-এ `_hmd()`-এর তালিকা `[2,5,7,10,13,16,18,21,24,26,29]` করা হয়েছে (এক সংখ্যা, এক লাইন)। `sw.js` ক্যাশ → v165।

**যাচাই (Node):** ১৩০০–১৫৯৯ হিজরির সব মাসে দুই ফাংশনের দৈর্ঘ্য মিলেছে (০ অমিল); ±১৫,০০০ দিনে `approxHijriNow`-ধাঁচের রূপান্তর ও `hijriToGregorian` পুরো ঘুরে মিলেছে (০ অমিল)।

**আজকের তারিখে প্রভাব নেই:** বর্তমান বছর ১৪৪৮ (১৪৪৮ % ৩০ = ৮); ১৪৪৭ (= ৭) ও ১৪৪৮ দুটোই দুই তালিকাতেই লিপ/কমন একই। প্রভাব পড়ত ১৪৫৫–১৪৫৬ হিজরি (২০৩০-এর দশক) বা রেফারেন্সের (১৪৪৭) আগের বছরে।
