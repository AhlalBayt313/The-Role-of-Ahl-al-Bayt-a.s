# v202 — "আমার রমজান" কার্ড: "ক্রিম ও ফানুস" থিম

আপনার দেওয়া রেফারেন্স ছবির স্টাইলে নতুন থিম (ভেক্টরে আঁকা, ছবি-ফাইল নেই)।

- ক্রিম কাগজের ব্যাকগ্রাউন্ড; ওপরে ঝুলন্ত সোনালি চাঁদ, ফুল, তারা ও ছোট ফানুস; মাঝখানে তামাটে বড় ফানুস (সবুজ কাচ, চাঁদের চূড়া)।
- নিচের দুই কোণে সবুজ মসজিদ-আকৃতি, ধাপে ধাপে সোনালি রেখা, সোনালি গম্বুজ; মাঝখানে সোনালি পাখা-নকশা।
- গাঢ় সবুজ লেখা; রোজার রিং সোনালি (৩০ দিনের টিকসহ); প্যানেল সাদাটে কাচ + সবুজ বর্ডার।
- নতুন থিমটিই ডিফল্ট; আগের পান্না-সোনালি কার্ড "কার্ডের থিম" ড্রপডাউনে আছে।
- কার্ডের লেখা অপরিবর্তিত (রেফারেন্সের নমুনা লেখা নেওয়া হয়নি)। একমাত্র নতুন লেখা: ড্রপডাউনের লেবেল।
