## ৭. আজকের আমল (হোম)
অ্যাপের নিজস্ব ডেটা (`data/duas/metadata.json`-এর দোয়া/আমল/যিয়ারত) থেকে শুধু বেছে লিঙ্ক দেখায়। কোনো নতুন ধর্মীয় লেখা তৈরি করা হয়নি। হিজরি তারিখ `approxHijriNow()` থেকে, অর্থাৎ ক্যালেন্ডার পেজের ±১ দিন সমন্বয় মানে।

| কখন | কী দেখায় (আপনার ডেটার আইডি) |
|---|---|
| প্রতিদিন | সেদিনের দোয়া `dua-day-<বার>` |
| শুক্রবার | `amal-jumma-day`, `dua-quran-yawmul-jumuah`, `ziyarat-friday-mahdi` |
| বৃহস্পতিবার (আজ রাতে) | `amal-shab-e-juma` |
| ১০ মহররম | `amal-ashura-day`, `ziyarat-ashura`, `ziyarat-ashura-ghayr-marufa` |
| ১৫ রজব | `amal-umm-dawud` |
| ১৪ শাবান (আজ রাতে = ১৫ শাবানের রাত) | `amal-nisf-shaban`, `amal-salat-jafar-tayyar`, `amal-istegatha-imam-zaman` |
| রমজান | `day-N-dua-of-ramadan` + `amal-ramadan-daily` |
| রমজানের ১৮/২০/২২ তারিখ (আজ রাতে = ১৯/২১/২৩ তম রাত) | `amal-laylatul-qadr`, `dua-quran-laylatul-qadr-verse` |
| ১৮ জিলহজ | `dua-e-ghadir` |
| ১ শাওয়াল, ১০ জিলহজ | `dua-eid-takbir` |

“রাত” অংশ ইসলামি দিনের নিয়মে পরের হিজরি তারিখের (মাগরিবের পর শুরু) জন্য। রমজান ও শাবান মাসে কার্ডে “রমজান মোড” বোতাম আসে।

## ৮. রমজান মোড (`?page=ramadan`, “আরো” মেনুতে 🌙)
- আজ রমজানের কত তম দিন (অগ্রগতি বার); রমজানের বাইরে হলে “রমজান শুরু হতে প্রায় N দিন”।
- সেহরির শেষ সময় = ফজর, ইফতার = মাগরিব, aladhan থেকে, নামাজ পেজে আপনার বাছা জাফরি পদ্ধতি ও অবস্থান ব্যবহার করে (`prMethod()`/`prFetchMonth()`)। সরাসরি কাউন্টডাউন (ইফতার, বা মাগরিবের পর পরদিনের ফজর)। অফলাইনে সর্বশেষ সংরক্ষিত সময় (নোটিশসহ)।
- ৩০ দিনের রোজা ট্র্যাকার (শুধু আজ ও আগের দিন চিহ্নিত করা যায়), রাখা/বাদ পড়া সংখ্যা। ডেটা `ahlbayt_ramadan`-এ; ব্যাকআপে নতুন গ্রুপ “রমজান ট্র্যাকার” (ডিফল্ট চালু)।

## ⚖️ আপনার সিদ্ধান্ত/যাচাই
1. উপরের টেবিলের প্রতিটি সারি আপনার ডেটার `occasion` লেখা অনুযায়ী; শুক্রবারের যিয়ারত ও ঈদের তাকবির দুটি ছাড়া সব সরাসরি `occasion` থেকে। এই দুটি আপনার দেখে নিশ্চিত করা দরকার।
2. সেহরির শেষ = ফজর (ইমসাক নয়); কিছু মারজা সতর্কতার জন্য আগে শেষ করতে বলেন। পেজে ⚖️ নোট আছে।
3. মাগরিব (ইফতার) aladhan-এর জাফরি গণনা অনুযায়ী; আপনার এলাকার ঘোষিত সময়ের সাথে মিলিয়ে দেখুন।
4. হিজরি তারিখ ক্যালেন্ডার-ভিত্তিক; চাঁদ দেখার সাথে ১-২ দিন ফারাক হতে পারে।

## একটি পুরনো অসঙ্গতি (আমি বদলাইনি)
`approxHijriNow()` (script-1-core.js) লিপ-বছরের তালিকায় `15` ধরে, কিন্তু `getHijriMonthDays()`-এ (Bug #29 ফিক্সের পর) `16`। বছর `%30 == 15 বা 16` হলে (AH ১৪৫৫-১৪৫৬, প্রায় ২০৩৩-৩৪) দুই ফাংশনের হিসাবে এক দিনের ফারাক হবে। আজকের তারিখে কোনো প্রভাব নেই। চাইলে এটি ঠিক করে দেব।
