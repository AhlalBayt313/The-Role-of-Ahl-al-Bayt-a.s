# v169 — যাকাত: ফসলের খরচ বাদ দেওয়ার নোট স্পষ্ট করা

**বদল:** শুধু `khums-zakat.js`-এর একটি নোট (যাকাত ক্যালকুলেটরের তথ্য-তালিকায়)। আগে ছিল "বিধান মারজাভেদে ভিন্ন — মোট ফসলে হিসাব"; এখন: আয়াতুল্লাহ খামেনেয়ী ও মাকারেম শিরাজির ফতোয়ায় খরচ বাদ দেওয়া যায় (নিসাব বাদ দেওয়ার আগের মোট ফসলে), আয়াতুল্লাহ সিস্তানির মতে ওয়াজিব সতর্কতায় যায় না; ক্যালকুলেটর সতর্ক পক্ষে মোট ফসলে হিসাব করে। হিসাবের কোড বদলায়নি। `sw.js` → v169।

**সূত্র:** সিস্তানি — তাঁর অফিসিয়াল সাইটের তাওযীহুল মাসায়েল ১৯০০; মাকারেম — তাঁর দপ্তরের ইস্তিফতা। খামেনেয়ী — একটি ধর্মীয় প্রশ্নোত্তর ব্লগে উদ্ধৃত তাঁর উত্তর (অফিসিয়াল সাইট স্বয়ংক্রিয় অ্যাক্সেস আটকায়)।

## ⚖️ আপনার যাচাই
1. **খামেনেয়ীর বিধানটি** (khamenei.ir-এ) নিজে একবার মিলিয়ে নিন; অনানুষ্ঠানিক সূত্রে পেয়েছি।
2. **মিসকালের গ্রাম:** ৪.৬০৮ ঠিক আছে, বদল দরকার নেই। রিসালার "২০ শরঈ মিসকাল = ১৫ প্রচলিত মিসকাল" তখনই মেলে যখন শরঈ = ১৮ নখুদ (৩.৪৫৬ গ্রাম) ও প্রচলিত = ২৪ নখুদ (৪.৬০৮ গ্রাম) — অনুপাত ৪:৩। ৪.৬৮৭৫ গ্রাম বাজারের আলাদা সম্মত "মিসকাল মামুলি"; ওটা ধরলে এই সমীকরণ ভেঙে যায়।
