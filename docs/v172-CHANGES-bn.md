# v172 — দোয়ার হেডার সরু কলামে চেপে যাওয়া ঠিক (UX, mobile)

## ❌ → ✓ সমস্যা
- মোবাইলে দোয়া/যিয়ারত/আমল রিডারের হেডারে লেখার ব্লক (শিরোনাম, সোর্স, রেফারেন্স চিপ) মাত্র ~১০৪px চওড়া হয়ে যেত।
- ফলে শিরোনাম ভেঙে যেত, রেফারেন্স চিপ ~১০ লাইনের লম্বা ডিম্বাকৃতি হতো, মূল দোয়া শুরু হতো প্রায় এক স্ক্রিন নিচে।
- কারণ: লেখার ব্লকে `flex-1` (basis 0) ছিল, তাই `flex-wrap` কখনো কাজ করত না; পাশের বাটনগুলো (`flex-shrink-0`) জায়গা কেড়ে নিত।

## ✓ সমাধান
- নতুন ক্লাস `.dzx-head-main { flex: 1 1 280px; min-width: 0; }` (`assets/css/style.css`)।
- মোবাইলে বাটনগুলো শিরোনামের নিচের সারিতে নামে; ডেস্কটপে আগের মতো পাশাপাশি থাকে।
- ক্লাস যোগ হয়েছে ৩ জায়গায়:
  - `assets/js/core/script-3-pages.js` — দোয়া রিডার
  - `assets/js/core/script-4-boot.js` — যিয়ারত ও আমল রিডার
