# v191 — শবে কদরের রাতের ধাপ (রমজান পেজ)

নতুন ফাইল `assets/js/core/qadr-walk.js`। `renderRamadanPage` আরেকবার মুড়ে একটি কার্ড যোগ করে (typeof-গার্ডসহ; ভুল হলে মূল পেজ অক্ষত)।

- **কখন:** ১৯, ২১, ২৩ রমজানের রাতে (মাগরিব থেকে ফজর)। অন্য দিনে ছোট প্রিভিউ "পরবর্তী শবে কদর: …"। "ভুল রাত? বদলান" দিয়ে হাতে রাত বাছা যায়।
- **ধাপ:** `amal-laylatul-qadr`-এর §১২-এর ১০টি ধাপ, রান-টাইমে ডেটা থেকে পড়া (অফলাইন ফলব্যাক = হুবহু কপি)। চাপলে চেক হয়।
- **"খুলুন" বোতাম:** শুধু বিদ্যমান আইটেমে। ইমাম হুসাইন (আ.)-এর শবে কদরের যিয়ারত ও মুনাজাতে ইমাম আলী (আ.)-এর আইডি নেই, তাই লিংকহীন ধাপ।
- **রাত-ভিত্তিক বাড়তি:** §১১ থেকে।
- **জওশন কবীর:** ১০০টি ধুয়া-ভাগ, ঘরে চাপলে চিহ্ন, "পরবর্তী ভাগ" বোতামে ভাগের আরবি ও অর্থ।
- **সংরক্ষণ:** `ahlbayt_qadr_walk` → `{ "<বছর>-9-<রাত>": { steps, jawshan } }`; ব্যাকআপের "রমজান" গ্রুপে যোগ।
- **বদলানো ফাইল:** `index.html`, `sw.js` (v191, precache), `data-backup.js`, `style.css` (v191 ব্লক)।

নতুন কোনো ধর্মীয় লেখা যোগ হয়নি; ধাপ, বাড়তি আমল ও কাযা-সংক্রান্ত সতর্কবাক্য আমালের নিজের লেখা।

**পরীক্ষা:** `node --check`, স্মোক-টেস্ট, Node-এ ডেটা দিয়ে: ধাপ ১০টি, ধুয়া ১০০টি (১০১৪ লাইন সব ঢাকা), রাতের সময়-সীমা, ক্লিক ও সংরক্ষণ।
**ব্রাউজারে দেখা বাকি:** গ্রিডের চেহারা (মোবাইলে ৮ কলাম), ডার্ক মোড, স্ক্রল।
**জানা সীমা:** ব্যাকআপ "মার্জ" মোডে এই কী পুরোটা প্রতিস্থাপিত হয় (`ahlbayt_ramadan`-এর মতোই)। ইংরেজি মোডে ধাপের লেখা বাংলাতেই থাকে।
