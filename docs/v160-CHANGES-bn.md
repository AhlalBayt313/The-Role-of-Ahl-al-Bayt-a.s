# v160 — স্প্ল্যাশের সময় বাড়ানো (লেখা পড়ার সুযোগ)

**সমস্যা:** পূর্ণ ইন্ট্রোতে আয়াত/উক্তি পুরো স্পষ্ট হয় ~২.৮ সেকেন্ডে, কিন্তু স্প্ল্যাশ ৩.০ সেকেন্ডে বিদায় নিত — পড়ার সময় ~১ সেকেন্ড। ছোট ইন্ট্রোতে (১.৫ সে.) সব লেখা ০.৫ সেকেন্ডে এসে ~১ সেকেন্ড থাকত।

**বদল** (শুধু সময়, অ্যানিমেশনের ছন্দ অপরিবর্তিত):
- `index.html` `window.__splashMs`: পূর্ণ ইন্ট্রো ৩.০ → **৫.৫ সে.**; দুর্বল ডিভাইস ২.৮ → **৫.০ সে.**; ছোট ইন্ট্রো ১.৫ → **২.৮ সে.**; রিডিউসড মোশন ১.২ → **২.৮ সে.**। ফেইল-সেফ (সময় + ৪ সে.) নিজে থেকে বাড়ে। ট্যাপ/Esc/Enter-এ স্কিপ আগের মতো (০.৯ সে. পর)।
- `style.css`-এর শেষে নতুন ব্লক: সোনালি লোডিং বার নতুন সময় জুড়ে চলে (পূর্ণ: ১.৯ + ৩.৬ = ৫.৫ সে.; লাইট: ১.৪৯ + ৩.৫ ≈ ৫.০ সে.)। ছোট ইন্ট্রোতে বার লুকানো (আগের মতো), রিডিউসড মোশনে আগের স্ট্যাটিক নিয়ম।
- `sw.js` CACHE → v160।

## ⚖️ নোট
- দিনে একবার পূর্ণ ইন্ট্রো; পরের খোলায় ২.৮ সে.। দিনের চিহ্ন সেভ হয় ২.৪ সেকেন্ড পর (আগের মতো)।
- ফোনে চোখে দেখে সংখ্যা ঠিক লাগছে কি না যাচাই বাকি; কম/বেশি চাইলে `index.html`-এর ওই এক লাইনের সংখ্যা বদলালেই হয় (সঙ্গে CSS-এর বারের সময়: `__splashMs − ১.৯` সেকেন্ড)।
- `script-4-boot.js`-এর একটি পুরনো মন্তব্যে "6s fail-safe" লেখা আছে; এখন ফেইল-সেফ = সময় + ৪ সে.। মন্তব্য অপরিবর্তিত।
