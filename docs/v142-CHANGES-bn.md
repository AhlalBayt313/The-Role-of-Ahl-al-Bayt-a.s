4. h322-এর দ্বিতীয় বাক্য ("মিষ্টভাষী ব্যক্তি...") ইংরেজি অনুবাদে একই খুতবার অংশ; অর্থ মূলের সঙ্গে মিলিয়ে নেওয়া ভালো।
