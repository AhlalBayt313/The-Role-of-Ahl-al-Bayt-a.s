# v104 — মোবাইল হেডার সরল + নিচের ন্যাভ

(UX রিভিউয়ের প্রথম ধাপ। ডেটা/JSON/ধর্মীয় কনটেন্ট/রাউটিং অপরিবর্তিত।)

## ১. হেডার (মোবাইল < ৭৬৮px)
**❌ আগে:** মেনু, লোগো, সার্চ, A−/A+, 🔐, EN, থিম — ৭টি নিয়ন্ত্রণ এক সারিতে।
**✓ এখন:** মেনু, লোগো, সার্চ, থিম। বাকিগুলো সরানো হয়েছে —
| নিয়ন্ত্রণ | নতুন জায়গা |
|---|---|
| A−/A+ | মেনু ড্রয়ারের নিচে "হরফের আকার" সারি (৪৪px বোতাম) |
| EN/বাং | মেনু ড্রয়ারে আগে থেকেই ছিল (অপরিবর্তিত) |
| 🔐 অ্যাডমিন | মেনু ড্রয়ারের নিচে + পেজ ফুটারে ছোট লিংক |
- লগইন করা অ্যাডমিনের ADMIN/📊/লগআউট মোবাইলে ড্রয়ারে; ডেস্কটপ হেডারে আগের মতোই।
- ডেস্কটপ (≥৭৬৮px) হেডার হুবহু আগের মতো, শুধু লগআউট অবস্থায় 🔐 আর হেডারে নেই (ফুটারে)।

## ২. নিচের ন্যাভ
- লেবেল ৯.৫px → ১১.৫px।
- সক্রিয় ট্যাব: আইকনের পেছনে সবুজ পিল (আগে শুধু ৩px দাগ)।
- emoji → একই স্টাইলের স্ট্রোক SVG আইকন (হোম, ব্লগ, জ্ঞান কেন্দ্র, দোয়া, ক্যালেন্ডার)।
- বোতামের ন্যূনতম উচ্চতা ৫৬px।

## ফাইল
`script-2-ui.js` (renderHeader, renderMobileMenu, renderFooter), `script-4-boot.js` (renderMobileBottomNav), `style.css` (শেষে নতুন ব্লক), `sw.js` (CACHE v104)।

## এখনো বাকি (রিভিউয়ের পরের ধাপ)
তারিখের স্ট্রিপ, ক্যালেন্ডার ঘর, দোয়া কার্ড, ওয়াক্ত কার্ডের "লোড হচ্ছে…", পালিশ। ±১ হিজরি সমন্বয় এখনো ক্যালেন্ডার পেজে আছে।
