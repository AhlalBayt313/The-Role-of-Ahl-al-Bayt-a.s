# v121 — কুইজ উন্নয়ন (Quiz Plus)

আগে থেকে ছিল: সেটআপ/খেলা/ফলাফল, আজকের ৫ প্রশ্ন, টাইমার, ব্যাখ্যা, শেষে ভুলের তালিকা, ইতিহাস, সেরা স্কোর, অ্যাডমিন এডিটর। সেগুলো অক্ষত; নিচেরগুলো তার ওপর যোগ হয়েছে।

## নতুন কী
1. **XP, ৮টি লেভেল, ১২টি ব্যাজ** — সঠিক উত্তরে সহজ ১০ / মাধ্যম ১৫ / কঠিন ২০ XP; ৫+ প্রশ্নের কুইজে ১০০% হলে +২৫। লেভেল: তালিবে ইলম → শিক্ষার্থী → পাঠক → জ্ঞানান্বেষী → জ্ঞানী → নিবেদিত → বিশিষ্ট → ওস্তাদ (০/১০০/২৫০/৫০০/৯০০/১৪০০/২১০০/৩০০০ XP)।
2. **দৈনিক স্ট্রিক** — আজকের কুইজ প্রথমবার শেষ করলে "✅ সম্পন্ন (৪/৫)" দেখায়, টানা দিন গোনা হয় (+৩০ XP + ধারা×৫, সর্বোচ্চ ৭ দিন পর্যন্ত)। একই দিনে আবার খেললে অনুশীলন — স্ট্রিক/বোনাস বাড়ে না। একদিন বাদ গেলে ধারা ০, সেরা ধারা মনে থাকে।
3. **ভুলের ব্যাংক** — যেকোনো মোডে ভুল (বা সময় শেষ) হওয়া প্রশ্ন সেভ থাকে। "🔁 ভুল অনুশীলন" সেগুলো থেকেই কুইজ বানায়; পরপর ২ বার ঠিক হলে ব্যাংক থেকে সরে ("আয়ত্ত")। এই মোডের স্কোর "সেরা স্কোর" বদলায় না।
4. **ফ্ল্যাশকার্ড** — বর্তমান ক্যাটাগরি/কঠিনতা/সংখ্যা ফিল্টার অনুযায়ী: প্রশ্ন → "উত্তর দেখুন" → উত্তর + ব্যাখ্যা + সূত্র; "আবার দেখব" চাপলে প্রশ্ন ভুলের ব্যাংকে যায়। (নিজে "জানতাম" বললে ব্যাংক থেকে সরে না — শুধু স্কোরড উত্তরে সরে।)
5. **📊 আমার অগ্রগতি পেজ** — লেভেল/XP বার, ৮টি পরিসংখ্যান (মোট উত্তর, সঠিকের হার, কুইজ সংখ্যা, সেরা স্কোর, সেরা টানা সঠিক, ধারা, ব্যাংক, আয়ত্ত), ক্যাটাগরি-ভিত্তিক হার, ব্যাজ গ্রিড (লক/আনলক), "অগ্রগতি মুছুন"।
6. **ফলাফল স্ক্রিনে** — পাওয়া XP ও বোনাস, লেভেল-আপ ব্যানার, নতুন ব্যাজ, ক্যাটাগরি অনুযায়ী স্কোর, ধারা/আয়ত্ত লাইন, "ভুল অনুশীলন" বাটন। খেলার সময় ২+ টানা সঠিক হলে "🔥 N টানা" চিপ।
- সেটআপ স্ক্রিনের মাথায় প্রোফাইল কার্ড (লেভেল, XP, 🔥ধারা, 🎯হার, 🏅ব্যাজ) — ট্যাপ করলে অগ্রগতি পেজ।

## ⚠️ জেনে রাখুন
1. **প্রশ্নব্যাংক এখনো ১১৩টি** (ক্যাটাগরি প্রতি ~১৮–২১)। ফিচারগুলো যত ভালোই হোক, ব্যাংক বাড়ালেই আসল উপকার — আপনি/বিশেষজ্ঞ যাচাই করা প্রশ্ন দিলে `data/quiz/questions.json`-এ বসিয়ে দেব। ধর্মীয় প্রশ্নে ভুল তথ্যের ঝুঁকি থাকায় আমি নিজে নতুন প্রশ্ন বানাইনি।
2. **XP/ব্যাজ শুধু ডিভাইসে** (localStorage) — ফোন বদলালে বা ব্রাউজার ডেটা মুছলে হারাবে; ডিভাইস-সিঙ্কের ব্যবস্থা এখনো নেই।
3. **লেভেলের নাম** ("তালিবে ইলম … ওস্তাদ") ও XP-সংখ্যা আমার বাছাই — `QP_LEVEL_NAMES`/`QP_LEVELS`/`QP_XP`/`QP_BADGES`-এ এক জায়গায় বদলানো যায়।
4. **দৈনিক কুইজ** সবার জন্য একই ৫ প্রশ্ন (আগের মতোই), তারিখ ডিভাইসের লোকাল টাইমজোন ধরে।
5. 50:50-জাতীয় লাইফলাইন যোগ করিনি (স্কোরের ন্যায্যতা বদলে যায়) — চাইলে পরের ধাপে।
