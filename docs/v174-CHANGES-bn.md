# v174 — স্প্ল্যাশ স্ক্রিনের সময় বাড়ানো

## ✓ কী বদলেছে (`index.html`)
| অবস্থা | আগে (v160) | এখন |
|---|---|---|
| দিনের প্রথম খোলা (পূর্ণ ইন্ট্রো) | ৫.৫ সেকেন্ড | **৮ সেকেন্ড** |
| লাইট মোড (`lite`) | ৫ সেকেন্ড | **৭ সেকেন্ড** |
| একই দিনে পরের বার (`quick`) | ২.৮ সেকেন্ড | **৪ সেকেন্ড** |
| reduced-motion | ২.৮ সেকেন্ড | ২.৮ সেকেন্ড (ইচ্ছা করে অপরিবর্তিত — অ্যাক্সেসিবিলিটি) |

- মান বদলাতে চাইলে শুধু এই লাইন: `window.__splashMs = reduce ? 2800 : (quick ? 4000 : (lite ? 7000 : 8000));`
- স্ক্রিনে ট্যাপ / Esc / Enter দিলে (প্রথম ০.৯ সেকেন্ডের পর) আগের মতোই স্কিপ হয়।
- নিরাপত্তা-টাইমার (`__splashMs + ৪ সেকেন্ড`) নিজে থেকেই নতুন মানের সাথে বাড়ে।

## ✓ প্রোগ্রেস লাইন
- আগে প্রোগ্রেস লাইন ~২.৭ সেকেন্ডে ভরে যেত; সময় বাড়ালে বাকি সময় পুরো ভরা অবস্থায় বসে থাকত।
- এখন পূর্ণ/লাইট মোডে লাইনটি স্প্ল্যাশ শেষ হওয়ার ~০.৫ সেকেন্ড আগে পর্যন্ত ধীরে ভরে (`animationDuration` JS দিয়ে হিসাব করা)। quick/reduced-motion-এ অপরিবর্তিত।
