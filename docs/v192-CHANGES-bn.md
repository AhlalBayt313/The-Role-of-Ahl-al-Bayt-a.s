# v192 — রমজানের জার্নাল + "আমার রমজান" কার্ড

নতুন ফাইল `assets/js/core/ramadan-journal.js`। `renderRamadanPage` আরেকবার মুড়ে রমজান পেজের শেষে দুটি কার্ড-সেকশন যোগ করে (typeof-গার্ডসহ; ভুল হলে মূল পেজ অক্ষত)।

**১. জার্নাল**
- প্রতি রাতে এক লাইন (সর্বোচ্চ ১৬০ অক্ষর), ধরন: নিয়ত বা কৃতজ্ঞতা। লেখা ব্যবহারকারীর নিজের; অ্যাপ কিছু লেখে না।
- রাত গোনা: আগের মাগরিব থেকে নতুন রাত শুরু (শবে কদরের কার্ডের মতোই)। রাত-বাছাইয়ে আজ পর্যন্ত যেকোনো রাতের লাইন লেখা/বদলানো/মোছা যায়। লেখা যায় শুধু রমজান মাসে; পরে দেখা ও কার্ড চলে।
- সংরক্ষণ: `ahlbayt_ramadan_journal` → `{ "<বছর>": { "<রাত>": { t, k } } }`, শেষ ৫ বছর। শুধু এই ডিভাইসে।

**২. "আমার রমজান <বছর>" কার্ড**
- ১০৮০×১৩৫০ ছবি (ক্যানভাস): রোজা রেখেছি (রোজার হিসাব থেকে), জার্নালের লাইন সংখ্যা, শবে কদরের কয়টি রাতে ধাপ চিহ্নিত (`ahlbayt_qadr_walk` থেকে, ৩-এর মধ্যে)। অ্যাপের স্প্ল্যাশ-শিরোনাম ও ঠিকানা (ahlalbayt313.github.io) কার্ডে থাকে।
- **জার্নালের লেখা কার্ডে যায় না**, শুধু ব্যবহারকারী "একটি লাইন দিন" টিক দিয়ে লাইন বাছলে।
- শেয়ার ঐচ্ছিক (Web Share, না হলে ডাউনলোড) আর সংখ্যার লেখা কপি। কিছুই কোথাও পাঠানো বা জমা হয় না।
- কার্ডটি পুরো রমজান জুড়ে বানানো যায় (মাস শেষের অপেক্ষা নেই); রমজানের পরেও একই বছরের সংখ্যা দেখায়।

**বদলানো ফাইল:** `index.html` (script-ট্যাগ), `sw.js` (v192, precache), `data-backup.js` (একটি কী-লাইন + বর্ণনা-লেখা), `style.css` (v192 ব্লক)। কোনো ফাংশন বা নাম বদলায়নি।

**পরীক্ষা:** `node --check`, স্মোক-টেস্ট পাস; Node-এ: রাত গোনার সময়-সীমা (দিন/মাগরিব/মাঝরাত/৩০তম), সংরক্ষণ ও মোছা, HTML-মেশানো লেখা এস্কেপ হয়, কার্ডের সংখ্যা (রোজা/জার্নাল/শবে কদর), রমজানের আগে-পরে বছর।
**ব্রাউজারে দেখা বাকি:** কার্ডের চেহারা ও বাংলা ফন্ট, মোবাইলে শেয়ার-শিট, ডার্ক মোডে রং।
**জানা সীমা:** ব্যাকআপ "মার্জ" মোডে এই কী পুরোটা প্রতিস্থাপিত হয় (`ahlbayt_ramadan`-এর মতোই)। জার্নালের লেখা ব্যক্তিগত, তাই ব্যাকআপ ফাইলে গেলে সেটাও রক্ষা করুন; "রমজান ট্র্যাকার" বন্ধ রাখলে জার্নালও ব্যাকআপে যায় না।
