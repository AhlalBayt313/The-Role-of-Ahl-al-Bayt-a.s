# v149 — জ্ঞান কেন্দ্রে নতুন হাদিস না দেখানোর সমস্যা ঠিক

## সমস্যা
জ্ঞান কেন্দ্র তালিকা ও সংখ্যা দেখায় `data/knowledge/metadata.json`-এর `kcHadiths` (হালকা ইনডেক্স) থেকে। `hadith.json` শুধু ইনডেক্সে থাকা id-গুলোর পূর্ণ তথ্য (সূত্র, বর্ণনাকারী) ভরে দেয় — ইনডেক্সে নেই এমন হাদিস দেখায় না। ইনডেক্সে ছিল ১৭৫টি (h001–h246-এর মধ্যে), তাই h247–h496 (২৫০টি) `hadith.json`-এ থাকলেও পেজে আসেনি।

## সমাধান
`metadata.json`-এর `kcHadiths`-এ ২৫০টি এন্ট্রি যোগ (শুধু `id`, `category`, `textBn`, `textEn`); আগের ১৭৫টি অপরিবর্তিত। এখন মোট ৪২৫। ফাইলের ফরম্যাট (কমপ্যাক্ট JSON) একই। `sw.js` ক্যাশ → v149।

## নিয়ম (এখন থেকে)
নতুন হাদিস যোগ করলে `hadith.json` ও `metadata.json` — দুটোতেই যোগ করতে হবে।
