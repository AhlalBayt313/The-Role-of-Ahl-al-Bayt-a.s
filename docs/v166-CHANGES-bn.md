# v166 — খুমস ও যাকাত: আয়াতুল্লাহ খামেনেয়ীর রিসালার সঙ্গে নিসাব মেলানো

**যাচাই (মারজা: আয়াতুল্লাহ আলী খামেনেয়ী):**
- **শস্য (গম, যব, খেজুর, কিশমিশ):** তাঁর দপ্তরের অফিসিয়াল সাইটে (khamenei.ir, তাওযীহুল মাসায়েল মাসআলা ১৮৬৪) নিসাব = ২৮৮ মন তাবরিজ − ৪৫ মিসকাল = **৮৪৭.২০৭ কেজি**। অ্যাপে ছিল ৮৪৭ → `KZ_CROP_NISAB_KG = 847.207` করা হলো (পর্দায় এখনো "৮৪৭ kg" দেখায়; ৮৪৭.০–৮৪৭.২ কেজির ফসলের ক্ষেত্রে হিসাব এখন সঠিক)।
- **সোনা-রুপা:** সোনা ২০ শরঈ মিসকাল = ১৫ প্রচলিত মিসকাল; রুপা ১০৫ প্রচলিত মিসকাল; পরের ধাপ সোনা ৪ শরঈ (= ৩ প্রচলিত), রুপা ২১ প্রচলিত মিসকাল — এগুলো ইমাম খোমেনী/সিস্তানি/বাহজাত প্রমুখের পাঠে একই, অ্যাপের মানের সঙ্গে মেলে। খামেনেয়ীর সাইট স্বয়ংক্রিয় অ্যাক্সেস আটকায়, তাই তাঁর সোনা-রুপার পাতা সরাসরি দেখিনি।

**বদল:** শুধু `KZ_CROP_NISAB_KG` (ও মন্তব্য), `sw.js` ক্যাশ → v166।
