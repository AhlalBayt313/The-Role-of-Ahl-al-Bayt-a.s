# v168 — ক্যালেন্ডারে দোয়ার লিংক (ঈদ, মুবাহালা, ২৭ রমজান)

**কী বদলেছে:** `CAL_EVENT_LINKS`-এ নতুন লিংক-ধরন `'d'` (দোয়া)। দোয়ার আইডি থেকে `duas` অ্যারেতে তার ইনডেক্স বের করে বিদ্যমান `readDua` অ্যাকশন দিয়ে খোলে (যিয়ারত/আমলের মতোই; আইডি না মিললে বাটন বাদ পড়ে, ডেটা তখনো না এলে খালি থাকে)। প্যানেলের শিরোনাম: "সংশ্লিষ্ট যিয়ারত, আমল ও দোয়া"।

| দিন | লিংক (সবই ডেটায় আগে থেকে ছিল) |
|---|---|
| ১ শাওয়াল (ঈদুল ফিতর) | ঈদের তাকবির, দোয়ায়ে নুদবা |
| ১০ যিলহজ (ঈদুল আযহা) | ঈদের তাকবির, দোয়ায়ে নুদবা |
| ২৪ যিলহজ (ঈদে মুবাহালা) | মুবাহালার আয়াত |
| ২৭ রমজান | লাইলাতুল কদরের মর্যাদার আয়াত |

কোনো JSON বদলায়নি; `sw.js` ক্যাশ → v168। যাচাই: JS সিনট্যাক্স ঠিক; স্টাব-ডেটায় রেন্ডার পরীক্ষা (সঠিক `readDua` ইনডেক্স, ডেটা না থাকলে খালি) পাস; চারটি আইডিই `metadata.json`-এ আছে।

## ⚖️ আপনার যাচাই
1. দোয়ায়ে নুদবা চার ঈদে (ফিতর, আযহা, গাদীর, জুমা) পড়ার প্রচলন মাফাতীহে আছে — গাদীরের (১৮ যিলহজ) লিংকে এখন যোগ করিনি; চাইলে বলুন।
2. ২৭ রমজানে শবে কদরের আমল (`amal-laylatul-qadr`) যোগ করিনি, কারণ তার বিষয়বস্তু ১৯/২১/২৩ রাতের।
3. এখনো লিংকবিহীন: ১ ও ৭ মুহাররম, ২ সফর (কারবালা থেকে বন্দিদের যাত্রা), ২৭ রজব — মানানসই কোনো যিয়ারত/আমল/দোয়া ডেটায় নেই।
