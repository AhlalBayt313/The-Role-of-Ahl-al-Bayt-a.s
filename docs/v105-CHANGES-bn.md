# v105 — পালিশ ও পরিচয় (UX রিভিউয়ের 🟢 অংশ)

ডেটা/JSON/ধর্মীয় কনটেন্ট/রাউটিং অপরিবর্তিত। শুধু CSS (শেষে নতুন ব্লক) ও কয়েকটি টেমপ্লেট।

## ১. Hero — splash-এর পরিচয়
- **"আল্লাহ" ক্যালিগ্রাফি:** splash-এর `splash-allah.svg` (ইতিমধ্যে precached) CSS mask দিয়ে hero-র মাঝখানে বড় করে, সোনালি গ্রেডিয়েন্টে, লেখার পেছনে (ডার্ক .17 / লাইট .14 opacity)। নতুন ইমেজ ফাইল নেই।
- **সোনালি রিং:** hero-র চারপাশে সোনালি বর্ডার + ভেতরে হালকা ইনসেট রিং (splash ফ্রেমের মতো)।
- **ডার্ক মোড:** নীল-বেগুনি (#0f172a→#1e3a8a) সরিয়ে গাঢ় সবুজ (#065f46→#011b15)। নীল orb সোনালি।
- **লাইট মোড:** নীলচে প্রান্ত সরে হালকা সোনালি-ক্রিম।
- **CTA বোতাম:** ইমামগণ = সবুজ (মূল), দোয়া = সোনালি, ব্লগ = ঘোস্ট। আগের বেগুনি/নীল বাদ।

## ২. ২টি অ্যাকসেন্ট (সবুজ + সোনালি)
- বিভাগ-কার্ড: "শিক্ষা ও ইতিহাস" গ্রুপ সবুজ, "ইবাদত ও টুলস" গ্রুপ সোনালি। ক্যাটেগরি চেনা যায় আইকন ও তার টিন্টে। (আগে নীল/বেগুনি/লাল/টিল।)
- হোমের ক্যালেন্ডার কার্ড তিনটি: সোনালি-গাঢ় / সবুজ / গাঢ় সবুজ। লাল হেডিং ব্যাজ সোনালি।
- আজকের হাদিস উইজেট: বেগুনি/নীল → সবুজ-ক্রিম (ডার্কে গাঢ় সবুজ)। কুইজ উইজেটের লাল ব্যাজ সোনালি।
- মৌলিক অর্থবোধক রং (সতর্কতা = কমলা, ত্রুটি = লাল) অপরিবর্তিত।

## ৩. টাইপোগ্রাফি — ৩ স্তর
`--fs-title 18px / --fs-sub 14px / --fs-label 12px` + ক্লাস `.t-title .t-sub .t-label`।
প্রয়োগ: `.section-title` (২০.৮→১৮px), কার্ড h3 (১৪px), সাবগ্রুপ লেবেল ও hero stat লেবেল (১০px→১২px), hero stat সংখ্যা (১৮px)।
**বাকি:** দোয়া/জ্ঞান কেন্দ্র/ক্যালেন্ডার পেজের ভেতরের শিরোনামগুলো এই ধাপে ধরা হয়নি।

## ৪. একই ডিজাইন-ভাষা
- নতুন `.ab-banner`, `.ab-btn`, `.ab-btn-gold`: গাঢ় সবুজ পৃষ্ঠ, সোনালি বর্ডার, ১৬px radius, ৪০px বোতাম।
- প্রয়োগ: ইনস্টল ব্যানার (টেমপ্লেট বদল), টোস্ট (success/info), হোমের পরবর্তী-নামাজ ব্যানার, কার্ড radius।
